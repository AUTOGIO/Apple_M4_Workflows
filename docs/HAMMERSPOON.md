# Hammerspoon relationship

This hub’s `docs/USER_GUIDE.html` documents **BlackDragon / Hammerspoon** automation that runs from the host tree `~/.hammerspoon`, not from this repository.

| Item | Location |
|------|----------|
| Live Lua modules (`guide.lua`, terminal ops, etc.) | `~/.hammerspoon/modules/` |
| Guide HTML (canonical in-repo) | `docs/USER_GUIDE.html` |
| Optional host install | Symlink: `~/.hammerspoon/USER_GUIDE.html` → this repo’s guide |

Do not delete or rewrite `~/.hammerspoon` from this repo. Reloading config remains a Hammerspoon menu / hotkey action on the Mac.
